收集、整理、复用 Prompt 的更顺手方式

这不是一个只负责“收藏”的工具。 它更像浏览器里的 Prompt 工作台，让你从采集开始，就把内容整理成后面可以直接使用的结构。

Capture

看到就收

在网页里遇到有价值的 Prompt，直接选中文本后右键保存。 不需要切换到别的软件，也不需要重新复制整理。

Structure

保存时就整理好

标题、正文和配图会优先进入对应位置。 这样保存下来的每条 Prompt 都更清晰，后面回看也更轻松。

Reuse

让收藏真正可复用

通过分类、搜索和一键复制，你保存下来的 Prompt 不只是“存过”，而是能在下一次创作时快速重新调用。
