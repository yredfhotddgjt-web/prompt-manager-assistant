安装使用

Chrome 浏览器

  1. 打开 chrome://extensions
  2. 开启右上角"开发者模式"
  3. 点击"加载已解压的扩展程序"
  4. 选择 extension 文件夹

Edge 浏览器

  1. 打开 edge://extensions
  2. 开启左下角"开发人员模式"
  3. 点击"加载解压缩的扩展"
  4. 选择 extension 文件夹

💡 提示：如需在本地 file:// 页面测试，请在扩展详情页打开"允许访问文件网址"

使用技巧

🎯

最佳捕获方式

从标题第一行开始，拖选到 Prompt 正文和图片附近，然后右键选择"保存为 Prompt"

如果网站结构导致图片没有自动带入，保持侧边栏里的草稿不关闭，再右键目标图片，图片会追加到当前草稿
